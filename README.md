# SnapView

Fast macOS image viewer for real photo culling work.

Current Version: `v2.7.1`

Language: [English](#english) | [한국어](#korean)

## SnapView Distribution Update

To manage distribution and updates more reliably and provide them consistently, SnapView will unify distribution through the Mac App Store starting with SnapView 3.0.

SnapView 2.7.1 is the final DMG release. No new DMG versions will be distributed after 2.7.1. Installed copies of 2.7.1 will remain usable, but they will not receive feature updates or bug fixes.

Starting with SnapView 3.0, the latest version and all future updates will be available only through the Mac App Store. We will keep improving SnapView with the goal of making it the best image viewer for Mac.

## Get SnapView

- Primary distribution: [SnapView on the Mac App Store](https://apps.apple.com/us/app/snapview-fast-image-viewer/id6762974261)
- Final DMG release: [GitHub Releases](https://github.com/youngchangjo/SnapView/releases/tag/v2.7.1)
- Official website: [snapview.snapworkslab.com](https://snapview.snapworkslab.com)
- Release history: [Public Release Notes](https://github.com/youngchangjo/SnapView/blob/main/RELEASE_NOTES.md)

## Requirements and Privacy

- macOS `14.0` or later
- The DMG and Mac App Store channels use the same opt-in privacy defaults and saved-choice behavior.
- SnapView works with files you open locally. Apple Photos access is requested only when you open Apple Photos features.

# SnapView

실사용 사진 선별 작업에 맞춘 macOS용 고속 이미지 뷰어입니다.

현재 버전: `v2.7.1`

언어: [English](#english) | [한국어](#korean)

## SnapView 배포 방식 변경 안내

배포와 업데이트를 보다 안정적으로 관리하고 일관되게 제공하기 위해, SnapView 3.0부터 배포 창구를 Mac App Store로 일원화합니다.

SnapView 2.7.1은 마지막 DMG 릴리즈입니다. 2.7.1을 끝으로 새로운 DMG 버전은 더 이상 배포하지 않습니다. 설치된 2.7.1은 계속 사용할 수 있지만, 기능 업데이트와 버그 수정은 제공되지 않습니다.

SnapView 3.0부터 최신 버전과 향후 업데이트는 Mac App Store에서만 제공합니다. SnapView는 앞으로도 최고의 Mac 이미지 뷰어가 될 수 있도록 꾸준히 개선해 나가겠습니다.

- macOS `14.0` 이상
- DMG와 Mac App Store는 동일한 opt-in 개인정보 기본값과 저장 동작을 사용합니다.
