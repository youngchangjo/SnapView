# SnapView

Fast macOS image viewer for reviewing, culling, and refining photos.

- Latest update: `3.0.1` — September 14, 2026
- [3.0.1 release notes](RELEASE_NOTES.md#v301--2026-09-14): Creative Suite, watermark, saving, and Edit History fixes.
- Available through the **Mac App Store only**
- Universal app for Apple silicon and Intel Macs
- Requires macOS `14.0` or later

[한국어](#korean) · [View SnapView on the App Store](https://apps.apple.com/us/app/snapview-fast-image-viewer/id6762974261) · [Release notes](RELEASE_NOTES.md)

## What SnapView does

- Supports 14 interface languages with Light, Dark, and System appearance; 3.0 improves coverage and readability across workspaces and settings
- Browse folders, ZIP archives, and Apple Photos quickly
- Review with Main, Grid, Filmstrip, Compare, Quick Check, and slideshow views
- Keep Creative Suite AI choices between sessions and set AI and watermark defaults in Settings
- Reuse thumbnails across views within the selected memory budget, with less repeated work during continuous arrow-key navigation
- Resize the collapsible Storage and Apple Photos Navigator sections from an equal-height default
- Cull with ratings, Pick/Reject, and color labels, and collapse or restore the Select Tray from the viewer
- Refine photos in Creative Suite while moving between images without losing drafts, review meaningful edit steps with bounded A/B snapshots, copy Light/Color/Curve/Film drafts across matching scene photos, and align a selected face across two to four Compare cells
- Improved large-folder indexing and RAW+JPG pairing, with metadata, export, and batch actions
- Use HDR-aware display and color-managed rendering on supported systems
- Bundled QuickSRNet Large x2 for on-device AI upscaling on Apple silicon, with comparison, an optional viewer Save Copy button, and an applied/original toggle that keeps completed results during zoom
- Choose consistently sized app icons and restore the selected appearance on relaunch
- Choose from 11 icons, including 3.0 Mono
- Back up settings to a file and compare versions; selectively restore with Supporter Pass, with undo included
- Try viewer AI preview before choosing Supporter Pass to save an AI copy
- Support ongoing development through lifetime Supporter Pass and the Founding Supporter state

## Install and update

Install SnapView from the Mac App Store. Updates are delivered by the App Store.

SnapView no longer provides a direct-download package, GitHub binary release, package-manager install, or a separate in-app updater. Old 2.x download instructions are historical and do not apply to version 3.0.0 or later.

Get SnapView on the Mac App Store. See the release notes for the latest changes.

## Privacy and access

The App Store build is sandboxed. SnapView accesses files and folders selected by the user and stores security-scoped bookmarks when persistent access is needed. Anonymous diagnostics and usage analytics remain opt-in.

## 설치와 업데이트

SnapView는 Mac App Store에서 설치하며 업데이트도 App Store가 제공합니다.

직접 다운로드 패키지, GitHub 바이너리 릴리즈, 패키지 매니저 설치, 별도 앱 내 업데이터는 더 이상 제공하지 않습니다. 과거 2.x 설치 안내는 기록일 뿐 3.0.0 이상에는 적용되지 않습니다.

SnapView는 Mac App Store에서 받을 수 있습니다. 최신 변경 사항은 릴리즈노트에서 확인할 수 있습니다.

## 개인정보와 파일 접근

App Store 빌드는 sandbox를 사용합니다. SnapView는 사용자가 선택한 파일과 폴더에 접근하며 지속 접근이 필요한 경우 security-scoped bookmark를 저장합니다. 익명 진단과 사용 분석은 사용자가 동의한 경우에만 활성화됩니다.
