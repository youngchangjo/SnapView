SUPPORTER PASS

SUPPORTER PASS

기본은 충분하게,
반복 작업은 더 강력하게.

A complete viewer for everyone. Deeper workflow tools for Supporters.

SnapView의 기본 보기, ZIP/RAW 탐색, 선별 흐름은 계속 열려 있습니다. Supporter Pass는 개발을 이어가기 위한 평생 후원 패스입니다. Rust 기반 빠른 썸네일 처리와 반복 방문 디스크 캐시, 반복 작업 확장, 보조 모니터 작업 공간을 더 편하게 만듭니다.

SnapView keeps core viewing, ZIP/RAW browsing, and culling open for everyone. Supporter Pass is a lifetime way to support development. It adds Rust-based faster thumbnail handling, persistent disk cache, deeper repeated-work tools, and an auxiliary monitor workspace.

Main, Grid, Filmstrip, Pro Layout View, Apple Photos, ZIP, HDR, Select Tray, drag handoff, and wider RAW/PSD/JPEG 2000/DICOM/EXR/TGA support remain core SnapView value. Opening and reviewing photos stays fast either way.

Supporter Supporter

후원자는 썸네일과 반복 작업이 더 빨라집니다.

Supporters get faster thumbnails and deeper workflow tools.

Rust 기반 빠른 썸네일 처리, 반복 방문 디스크 캐시, 더 많은 Quick Organize 프리셋, Batch Actions 레시피, 보조 모니터 작업 공간, HDR 세부 확인과 전용 앱 아이콘을 제공합니다.

Supporter Pass adds Rust-based faster thumbnail handling, persistent disk cache, more Quick Organize presets, more Batch Actions recipes, an auxiliary monitor workspace, detailed HDR checks, and dedicated app icons.

Feedback Feedback

Supporters help shape the next advanced tools.

빠른 내보내기와 배치 작업, 간단한 이미지 편집, 폴더 즐겨찾기, 모바일 앱 연동, 상세한 사용자화 같은 고급 기능을 Supporter Pass에 우선 적용할 계획입니다. 피드백과 문의도 먼저 확인합니다.

Planned advanced work includes faster export and batch tools, simple image editing, favorite folders, mobile app integration, and deeper customization, with priority rollout for Supporter Pass and earlier review of supporter feedback and support requests.

WHAT IT ADDS

WHAT IT ADDS

반복되는 사진 작업을 줄이는 혜택

Benefits that reduce repeated photo work

01

Rust 기반 빠른 썸네일 처리

Rust-based faster thumbnails

큰 폴더를 다시 열 때 썸네일을 더 빠르게 불러오도록 Rust 기반 썸네일 코어와 고급 캐시 흐름을 사용합니다.

Rust thumbnail core and advanced cache flows help large folders feel faster when you revisit them.

02

반복 방문 디스크 캐시

Persistent thumbnail disk cache

한번 만든 폴더와 ZIP 썸네일을 디스크에 유지해 같은 작업 세트를 다시 열 때 기다림을 줄입니다.

Keep generated folder and ZIP thumbnails on disk so returning to the same work set feels faster.

03

Quick Organize와 Batch Actions 확장

Expanded Quick Organize and Batch Actions

자주 쓰는 복사/이동 프리셋과 내보내기/정리 레시피를 더 많이 보관해 반복 전달 작업을 줄입니다.

Keep more copy/move presets and export or sorting recipes ready for repeated delivery work.

04

보조 모니터 작업 공간

Auxiliary monitor workspace

클라이언트나 리뷰 화면에는 사진을 크게 보여주고, 보조 화면에서는 썸네일, 정보, 선택 상태, 비교 맥락을 계속 정리합니다.

Show the photo clearly for client or review work while the second display keeps thumbnails, metadata, selections, and comparison context available.

05

HDR 세부 확인과 전용 앱 아이콘

HDR checks and dedicated app icons

HDR 표시 상태와 세부 신호를 확인하고, Dock과 앱 전환기에 표시할 Supporter 전용 아이콘을 선택할 수 있습니다.

Check detailed HDR display signals and choose dedicated Supporter icons for the Dock and app switcher.

06

계획 중인 고급 기능 우선 적용

Priority rollout for planned advanced tools

빠른 내보내기, 간단한 이미지 편집, 폴더 즐겨찾기, 모바일 앱 연동, 상세한 사용자화 같은 기능을 Supporter Pass에 먼저 적용할 계획입니다. 피드백과 문의도 우선 확인합니다.

Planned work includes faster export, simple image editing, favorite folders, mobile app integration, and deeper customization, with priority rollout for Supporter Pass and earlier feedback review.

FOUNDING VS SUPPORTER

FOUNDING VS SUPPORTER

Founding은 초기 참여 표시입니다.

Founding is launch-window recognition.

Supporter Pass와 Founding Supporter의 실제 기능 혜택은 같습니다. Founding은 출시 초기 3개월 동안 참여한 사용자에게 남는 배지와 초기 가격을 더한 표시입니다. 나중에 일반 Supporter Pass로 전환되어도 기본 혜택 구조는 이어집니다.

Supporter Pass and Founding Supporter provide the same feature benefits. Founding adds launch-window pricing and a badge for early supporters during the first three months. After the founding window, the regular Supporter Pass keeps the same benefit structure.
