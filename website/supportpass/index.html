02 · NEW 3.0

AI 자동 1차 선별

AI-powered first-pass culling

Pick과 Reject 후보를 한 번의 분석으로 정리합니다. 원본 파일은 자동으로 변경하지 않으며 최종 선택은 사용자가 결정합니다.

Organize Pick and Reject candidates in one analysis pass without automatically changing source files. You keep the final choice.

03 · NEW 3.0

Recipe Timeline과 Scene Sync

Recipe Timeline and Scene Sync

편집 단계와 A/B 스냅샷을 보관하고, 같은 장면의 사진에 주요 보정을 초안으로 복사합니다.

Keep meaningful edit steps and A/B snapshots, then copy key adjustment drafts across matching photos.

04

빠른 썸네일과 디스크 캐시

Faster thumbnails and disk cache

Rust 기반 썸네일 처리와 반복 방문 디스크 캐시로 큰 폴더와 ZIP을 다시 열 때 기다림을 줄입니다.

Rust-based thumbnail handling and persistent disk cache reduce waiting when you revisit large folders and ZIP archives.

05

Quick Organize와 Batch Actions 확장

Expanded Quick Organize and Batch Actions

자주 쓰는 복사·이동 프리셋과 내보내기·정리 레시피를 더 많이 보관해 반복 작업을 줄입니다.

Keep more copy, move, export, and organization presets ready for repeated delivery work.

06

보조 모니터, HDR 확인, 전용 아이콘

Second display, HDR checks, and icons

보조 모니터 작업 공간, HDR 세부 확인, Supporter 전용 앱 아이콘 선택을 사용할 수 있습니다.

Use the auxiliary monitor workspace, detailed HDR checks, and dedicated Supporter app icon choices.
