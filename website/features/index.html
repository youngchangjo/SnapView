SnapView Features

The core tools for fast Mac photo review, folder-first browsing, and lightweight culling before editing.

Key Features

  • No import process or heavy catalog generation
  • Ultra-fast directory browsing and keyboard preview navigation
  • Browse ZIP archives in real time without extracting
  • 4 versatile view modes (Main / Grid / Filmstrip / Pro Layout) NEW 2.0
  • Pro Layout View with Action Strip, Info Strip, and thumbnail context NEW 2.0
  • Quick Organize with 3 visible presets, GPS map review, and 3 previewed batch recipes NEW 2.0
  • Apple Photos browsing, Photos-style Favorite heart, and Photos ↔ disk copy workflows NEW 2.5
  • HDR photo viewing, quick HDR/SDR switching, and non-AI upscaling NEW 2.5
  • Consistent sorting across Main, Grid, and Filmstrip with counter/context-menu controls NEW 2.5
  • Select Tray candidate/final/excluded sets and selected-original handoff NEW 2.5
  • Drag handoff from Main, Grid, and Filmstrip to Finder, Desktop, editing apps, and Photos NEW 2.5
  • Command-P print and PDF save for current images, selections, folders, ZIP archives, Apple Photos collections, and contact sheets NEW 2.5
  • Multi Monitor Workspace for Navigator, Quick Check, Histogram, Map, Filmstrip, and Select Tray panels NEW 2.5
  • Persistent thumbnail disk cache for repeat Grid, Filmstrip, and Navigator browsing NEW 2.5
  • Optional Supporter Pass for continued development, with Mac App Store purchase restore NEW 2.5
  • Real-time playback/view of RAW, HEIC, and animated formats
  • Adjustable Smart Decoding Modes (Speed vs Quality priority)
  • Intuitive Fullscreen Slideshow review with transition effects
  • Real-time culling sync with Lightroom (XMP Rating, Pick/Reject)
  • Seamless integration with macOS Finder color tags
  • Visual Duplicate checking and batch cleaner
  • Side-by-side multiple image Compare Mode (up to 4 images)
  • AI-assisted Quick Check for blink, focus, and exposure signals
  • Image Export for smaller sharing copies (JPEG/PNG, social presets)
  • On-device OCR to recognize and copy text from photos
  • Capture date/GPS edits for supported photos
  • Intuitive Histogram, detailed EXIF info, and GPS Map panels
  • Seamless keyboard-centric File Management (Select/Copy/Paste/Delete)
  • Convenient Always On Top mode for multi-tasking

Supported Formats

Still Images EXPANDED 2.5

JPG, PNG, GIF, BMP, WEBP, HEIC, HEIF, TIFF, PSD, JPEG 2000, DICOM, EXR/HDR, TGA, ICNS

Video

MP4, MOV, M4V

Archives and Metadata

Direct ZIP archive browsing, XMP sidecar writing for ratings and flags

Fast Review Workspace

  • RAW and image browsing: open RAW, JPG, PNG, HEIC, TIFF, and supported video files directly from folders.
  • Direct ZIP browsing: inspect archived albums without extracting them first.
  • Keyboard-first views: switch with Q, W, E, R, T, and Tab.

Pro Layout View

Press Tab to bring folder navigation, filmstrip context, action controls, photo information, ratings, and color labels into one review surface.

Culling And Organization

  • Quick Organize: run up to three visible copy or move presets for repeated sorting.
  • Batch Actions: preview up to three export, copy, or move recipes before applying them.
  • Finder and Lightroom handoff: keep Finder tags and XMP-backed ratings available outside SnapView.

Inspection Tools

  • Quick Check: review focus, exposure, and closed-eye signals without handing decisions to automation.
  • Map Overlay: see GPS-backed location context beside the photo when location data exists.
  • Compare and Duplicate: inspect similar shots side by side and clean exact duplicate files.

ZIP 및 메타데이터

압축 해제 없는 ZIP 바로 탐색, 별점과 플래그용 XMP Sidecar 쓰기

빠른 리뷰 작업 공간

  • RAW와 이미지 탐색: RAW, JPG, PNG, HEIC, TIFF, 지원되는 동영상을 폴더에서 바로 엽니다.
  • ZIP 바로 탐색: 압축을 먼저 풀지 않고 보관된 앨범을 확인합니다.
  • 키보드 중심 보기: Q, W, E, R, T, Tab으로 흐름을 유지합니다.

프로 레이아웃 보기

Tab을 누르면 폴더 탐색, 필름스트립, 작업 버튼, 사진 정보, 별점, 색상 라벨을 한 화면에서 함께 볼 수 있습니다.

선별과 정리

  • 빠른 정리: 자주 쓰는 복사 또는 이동 프리셋을 최대 3개까지 보이게 두고 반복 작업을 빠르게 처리합니다.
  • 일괄 작업: 내보내기, 복사, 이동 레시피를 최대 3개까지 미리 확인한 뒤 적용합니다.
  • Finder와 Lightroom 연동: Finder 태그와 XMP 기반 별점을 SnapView 밖에서도 이어서 사용합니다.

검토 도구

  • 빠른 체크: 초점, 노출, 눈 감음 신호를 확인하되 최종 판단은 사용자가 유지합니다.
  • 지도 오버레이: GPS 정보가 있는 사진은 촬영 위치 맥락을 함께 봅니다.
  • 비교와 중복 정리: 비슷한 사진을 나란히 보고 완전 중복 파일을 정리합니다.
