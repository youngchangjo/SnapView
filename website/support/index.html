버전 안내: DMG vs Mac App Store

SnapView는 두 가지 방식으로 제공됩니다. 업데이트 속도와 설치 방식을 기준으로 선택해 주세요.

홈페이지 다운로드 버전 (DMG)

가장 빠르게 최신 기능을 사용할 수 있는 직접 배포 버전입니다.

  • ZIP 파일을 풀지 않고 내부 이미지를 바로 탐색
  • 폴더, ZIP, 이미지 파일을 빠르게 열고 탐색
  • Sparkle 기반 업데이트 제공
  • 신규 기능과 개선 사항이 가장 먼저 반영되는 채널
  • 샌드박스 제약이 없어 파일 관리/정리 워크플로우에 더 유연함

고급 사용자이거나 최신 기능을 먼저 사용하고 싶다면 DMG 버전을 권장합니다.

Mac App Store 버전

Apple의 샌드박스 정책을 준수하는 App Store 배포 버전입니다.

  • Mac App Store를 통한 간편한 설치 및 업데이트
  • ZIP 파일 내부 이미지 직접 탐색 지원
  • 폴더/이미지/ZIP 탐색 등 핵심 뷰어 기능 제공
  • 파일이나 폴더 접근 시 macOS 권한 허용 과정이 표시될 수 있음
  • App Store 심사와 안정화 과정을 거친 버전으로 제공

설치와 업데이트를 App Store에서 관리하고 싶거나, 샌드박스 기반 배포를 선호한다면 Mac App Store 버전을 선택해 주세요.

Version Differences: DMG vs Mac App Store

SnapView is distributed in two different ways. Please choose based on your preferred update speed and installation method.

Website Download Version (DMG)

A direct distribution version where you can use the latest features fastest.

  • Directly browse images inside ZIP files without extracting
  • Quickly open and browse folders, ZIPs, and image files
  • Sparkle-based built-in updates
  • The first channel to receive new features and improvements
  • No sandbox restrictions, offering more flexibility for file management and organization workflows

We recommend the DMG version if you are an advanced user or want to use the latest features first.

Mac App Store Version

An App Store distribution version that complies with Apple's sandbox policies.

  • Convenient installation and updates via the Mac App Store
  • Supports direct browsing of images inside ZIP files
  • Provides core viewer features such as folder/image/ZIP browsing
  • macOS permission prompts may appear when accessing files or folders
  • Provided as a stable version that has passed the App Store review process

Choose the Mac App Store version if you prefer to manage installations and updates through the App Store, or if you prefer sandbox-based distribution.
