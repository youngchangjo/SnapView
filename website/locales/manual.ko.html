SnapView 사용자 매뉴얼

이 문서는 SnapView를 처음 사용하는 사용자가 설치부터 선별 작업까지 혼자 진행할 수 있도록 만든 실사용 안내서입니다.

1. SnapView가 무엇인가요?

  • SnapView는 macOS용 초고속 이미지 뷰어입니다.
  • 무거운 카탈로그 생성 없이 폴더/ZIP을 바로 열어 빠르게 감상하고 선별할 수 있습니다.
  • Lightroom 같은 편집 도구를 대체하기보다, 그 전에 빠르게 보고 고르는 단계에 집중합니다.

2. 이런 분께 추천합니다

  • 여행/일상/가족 사진을 많이 찍는 분
  • RAW 파일도 보지만 무거운 워크플로우가 부담스러운 분
  • 빠르게 훑고 좋은 컷만 남기고 싶은 분
  • 폴더 기반으로 간단히 관리하고 싶은 분

3. 설치와 첫 실행

3.0 배포 채널 선택 (중요)

  • Mac App Store 버전은 sandbox 안정판 채널입니다.
  • DMG 버전은 직접 다운로드 채널이며, 빠른 배포와 Sparkle 업데이트 흐름을 사용합니다.
  • DMG 버전은 단일 유니버설 앱으로 제공되며 Apple Silicon과 Intel Mac을 같은 다운로드로 지원합니다.
  • Apple Silicon을 기본 검증 환경으로 유지합니다.

3.1 설치

채널별 설치 방법은 아래와 같습니다.

  1. DMG 채널(Fast): 릴리즈에서 SnapView.dmg를 내려받아 SnapView.app을 Applications로 드래그해 설치합니다.
  2. Mac App Store 채널(Stable): Mac App Store에서 SnapView를 설치합니다.
  3. DMG 채널은 Apple Silicon과 Intel Mac을 포함한 단일 유니버설 앱으로 제공합니다.

3.2 처음 실행 시

  • macOS 보안 경고가 뜨면:
    1. 시스템 설정 -> 개인정보 보호 및 보안
    2. 실행 허용
    3. 앱 재실행
  • 첫 실행 화면에서 기본 이미지 앱 등록 제안을 볼 수 있습니다.
  • 원치 않으면 건너뛰어도 사용에 문제 없습니다.

4. 5분 빠른 시작

  1. 열기(Open)로 폴더 또는 ZIP 파일을 엽니다.
  2. Q/W/E/R로 뷰 모드를 바꾸고, T로 Navigator를 켜고 끕니다. 정리용 레이아웃이 필요하면 Tab으로 프로 레이아웃 뷰를 엽니다.
  3. 파일명에 숫자가 들어간 경우 Finder식 자연 정렬을 사용하므로 클리앙-1, 클리앙-2, 클리앙-10 순서로 이동합니다.
  4. 좌/우 화살표로 넘기며 확인합니다.
  5. 만화 폴더나 ZIP은 B로 Comic Reading에 들어가고, 일반 사진 검토로 돌아오려면 다시 B를 누릅니다.
  6. 좋은 컷은 1~5로 별점, 불필요한 컷은 X로 Reject 표시합니다.
  7. 반복 복사/이동이 필요하면 빠른 정리 프리셋이나 Batch Actions 레시피를 사용합니다.
  8. Lightroom과 함께 쓰는 경우, SnapView에서 준 별점/Pick/Reject가 XMP sidecar 기준으로 그대로 이어집니다.
  9. Finder에서도 결과를 바로 보고 싶다면 태그를 함께 적용합니다. SnapView는 Finder의 7색 태그(빨간색/주황색/노란색/초록색/파란색/보라색/회색)를 그대로 따릅니다.
  10. 현재 보고 있는 파일을 Finder에서 바로 찾고 싶으면 Cmd + Return 또는 메뉴의 Show in Finder를 사용합니다.
  11. 비교가 필요하면 C로 Compare 모드에서 1~4장 비교합니다.
  12. Delete로 삭제하거나 Cmd+C로 복사해 정리합니다.
  13. 완전히 동일한 파일 정리는 Cmd+Shift+D로 중복사진정리에서 처리합니다.
  14. 동영상이 섞인 폴더는 사진과 함께 넘겨보고, Space로 재생/일시정지합니다. 재생이 끝난 뒤에도 Space 또는 재생 버튼으로 처음부터 다시 재생할 수 있고, Option + ←/→로 5초 단위 탐색을 할 수 있습니다.
  15. 공유용 작은 복사본이 필요하면 이미지 내보내기에서 JPEG/PNG와 프리셋 크기를 선택합니다.

4.1 v1.8.0 안정화 변경

  • Grid에서 Reject 또는 별점 필터를 켠 뒤 전체 선택을 해도 화면에 보이는 필터 결과만 선택합니다.
  • Filmstrip 영역에서 가로 스크롤을 지원합니다.
  • ARW, CR3, RW2, DNG와 JPG가 같은 이름으로 있을 때 RAW+JPG 묶음 관리가 더 안정적으로 동작합니다.
  • 동영상 재생 중 SnapView로 돌아올 때 재생 막대가 빈 초기 상태로 잠깐 표시되지 않도록 복원 흐름을 안정화했습니다.
  • 동영상에서 Option + ←/→ 탐색 후 기존 자동 숨김 동작은 유지하면서 재생 막대를 잠깐 표시합니다.
  • 같은 방향으로 이미지 회전을 반복해도 각 90도 단계가 정확하게 표시됩니다.
  • 텐키 +/-, 보기 메뉴 상태, 썸네일 네모 프레임, Help 창 가독성, 단색 뷰어 배경 동작을 함께 개선했습니다.

4.2 v1.7.0 안정화 변경

  • 마우스 휠과 트랙패드 스크롤의 이전/다음 이동 방향을 Main, Filmstrip, Manage, Video에서 같은 기준으로 맞췄습니다.
  • 자연스러운 스크롤 옵션과 스크롤 방향 직접 설정을 분리했습니다. 필요하면 마우스/트랙패드, 상하/좌우 축을 각각 따로 지정할 수 있으며, 방향 사용자화는 기본적으로 꺼져 있습니다.
  • 정보 오버레이 표시 상태를 기억합니다. 정보 오버레이를 끄면 Main View의 Pick/Reject, 별점, 컬러 라벨 표시도 함께 숨겨집니다.
  • 이미지 이동 시 확대 비율을 유지하는 옵션과 다크 모드의 완전 검은 뷰어 배경 옵션을 추가했습니다.
  • 상단 툴바 아이콘에 지원 언어별 툴팁을 추가했습니다.
  • 리사이즈 이미지가 원본으로 바뀔 때도 짧은 페이드로 자연스럽게 전환되며, 원본 전환 요청을 더 빠르게 시작합니다.
  • JPEG 회전 저장은 실제 저장 성공을 확인한 뒤 완료 안내를 표시하고, 저장 후 썸네일을 새로 고칩니다.
  • 파일 작업은 명시 선택 항목을 우선합니다. Grid/Manage에서 선택한 파일을 복사/삭제/이동할 때 폴더 전체가 잘못 대상으로 잡히지 않도록 정리했습니다.
  • 앱 내부 Move to Folder와 확인 없는 Delete/Backspace 휴지통 이동 옵션을 추가했습니다. 확인 없는 삭제 옵션은 기본 꺼짐이며, 영구 삭제가 아니라 macOS 휴지통 이동만 수행합니다.

5. 화면 구성 이해하기

  • 상단 툴바: 열기, 이전/다음, 뷰 모드 전환, 줌, 정보/퀵체크/히스토그램 토글, 선별 액션
  • 중앙 캔버스: 현재 이미지 표시
  • 모드별 보조 영역:
    • Grid: 썸네일 격자
    • Filmstrip/Manage: 하단 또는 사이드 영역에서 연속 탐색
    • 상세 EXIF/Quick Check 패널: 정보 분석용

6. 뷰 모드별 사용법

6.1 Main View ( W)

  • 한 장에 집중해서 확인할 때 사용합니다.
  • 0으로 Fit, 9로 100%를 빠르게 전환합니다.
  • I로 간단 정보 오버레이를 켜고 끌 수 있습니다.
  • 큰 이미지를 열 때 로딩으로 인해 이전 작업이 끊기지 않습니다.
  • 지원되지 않는 포맷이거나 너무 커서 바로 열리지 않는 이미지는 화면 안내에 따라 안전하게 열기를 눌러 확인해 보세요.

6.2 Grid View ( Q)

  • 많은 사진을 한 번에 훑을 때 사용합니다.
  • 화살표/마우스로 빠르게 이동하고 여러 장을 선택할 수 있습니다.
  • =/-로 썸네일 크기를 조절해 밀도를 맞춥니다.

6.3 Filmstrip View ( E)

  • 메인 이미지 + 연속 스트립으로 흐름을 유지하며 볼 때 좋습니다.
  • 연사/유사 컷을 빠르게 넘기며 감으로 선별하기 좋습니다.
  • 동영상이 포함된 폴더에서는 사진과 같은 흐름으로 동영상을 확인하고 재생할 수 있습니다.

6.4 사진관리모드 Manage ( R)

  • 폴더/필터/선택 상태를 보며 정리할 때 사용합니다.
  • 별점/플래그/태그를 적용하고 필터링해 결과를 정돈합니다.
  • Lightroom과 함께 사용하는 경우, SnapView에서 끝낸 1차 선별 결과를 sidecar(XMP) 기준으로 그대로 넘기기 좋습니다.
  • 폴더 태그를 같이 쓰면 SnapView 밖에서도 Finder 기준 폴더 단위 정리 상태가 즉시 보입니다.
  • 관리뷰 왼쪽 네비게이터에서는 폴더 row의 색상 점과 폴더 태그 필터로 현재 작업 상태를 빠르게 좁힐 수 있습니다.
  • 동영상 파일도 사진과 같은 목록 안에서 확인하고 재생할 수 있습니다.

6.5 중복사진정리 Duplicate (Cmd+Shift+D)

  • 상단에서 Exact와 Same Photo를 전환할 수 있습니다.
  • Exact는 현재 소스에서 완전히 동일한 파일만 그룹으로 보여줍니다.
  • Same Photo는 용량/해상도/포맷이 달라도 같은 컷으로 보이는 사진을 검토용으로 묶습니다.
  • 좌측 그룹 목록에서 항목 수/절감 용량을 보고 그룹을 선택합니다.
  • 행 오른쪽의 미니 썸네일(5x2, 최대 10칸 + +N)로 그룹 구성을 빠르게 확인할 수 있습니다.
  • 상단 정렬/필터(정렬, 멤버 수, 날짜)로 먼저 범위를 좁히고 작업하면 안전합니다.
  • 그룹이 4장 이하면 중앙 메인 영역에서 바로 다중 비교하고, 5장 이상이면 하단 스트립이 추가로 표시됩니다.
  • 기준이미지는 기준이미지로 지정으로 변경할 수 있고, 각 카드의 X로 개별 즉시 삭제할 수 있습니다.
  • 우측 처리 패널에서 Exact 모드일 때만 현재이미지 병합 / 중복사진 일괄 정리 / 삭제 되돌리기를 수행합니다.
  • Same Photo는 검토/비교 중심 모드이며 자동 병합과 일괄 정리는 제공하지 않습니다.
  • 삭제 되돌리기(⌘Z)는 직전에 삭제한 사진 그룹만 복원합니다.

6.6 슬라이드쇼 (Shift + Enter)

  • 슬라이드쇼는 전체화면으로 실행됩니다.
  • 기본 시작/종료 키는 Shift + Enter입니다.
  • Shift + Space는 레거시 호환용으로 남아 있지만, 한국어 입력 환경에서는 Shift + Enter 쪽이 더 안정적입니다.
  • 기본값은 진입 시 바로 재생 ON이라 시작과 동시에 재생되고, 설정에서 끄면 전체화면 진입 직후 일시정지 상태로 시작합니다.
  • 현재 화면에 표시되고 있는 사진 결과를 기준으로 슬라이드쇼가 시작됩니다.
  • Compare와 중복사진정리에서는 시작하지 않습니다.
  • 시작 직후 상단 중앙에 무엇이 재생되는지를 보여주는 scope chip이 잠깐 나타나고, 좌상단에는 현재 위치 배지가 보입니다.
  • 하단 재생 컨트롤 도구(HUD)는 항상 화면에 보입니다.
    • 이전 / 재생·일시정지 / 다음
    • 속도 (3초처럼 현재 선택값 표시)
    • 전환 (하드 컷, 크로스페이드, 블랙 페이드 같은 현재 선택값 표시)
    • 루프 (원형 아이콘 토글)
    • 셔플 (원형 아이콘 토글)
    • 작은 이미지 확대 (원형 아이콘 토글)
    • 종료
  • 재생 중 1.2초 정도 입력이 없으면 커서는 자동으로 숨겨질 수 있습니다.
  • 슬라이드쇼 중에는 재생 전용 키가 우선이므로, 별점 / Pick / Reject / 태그 편집은 하지 않는 것이 기본입니다.
  • 전환은 설정에서 하드 컷 / 크로스페이드 / 블랙 페이드 중에서 선택할 수 있습니다.
  • 부드러운 화면 전환을 원하면 크로스페이드를 사용해 보세요.
  • 작은 이미지는 기본적으로 전체화면에 맞게 확대됩니다. 원본 100% 크기로 보고 싶으면 HUD 또는 도구 > 작은 이미지 확대 끄기로 바로 바꿀 수 있습니다.

7. 선별 도구 (가장 많이 쓰는 기능)

7.1 별점

  • 1~5: 별점 부여
  • 0 또는 \(원화키 포함): 별점 해제
  • 별점은 sidecar(XMP)에 저장되어 Lightroom 계열 도구에서도 그대로 이어집니다.
  • 즉, SnapView에서 빠르게 고르고 Lightroom에서 후반 작업하는 흐름에 잘 맞습니다.

7.2 Pick / Reject / Unflag

  • P: Pick
  • X: Reject
  • U: Unflag
  • Pick/Reject도 sidecar(XMP) 기준으로 저장됩니다.
  • 빠른 선별은 SnapView에서 하고, 선택 결과 확인과 보정은 Lightroom으로 넘기는 방식에 유리합니다.

7.3 Finder 태그

  • SnapView는 Finder의 태그 이름과 색상 순서를 그대로 사용합니다.
  • 지원 색상은 빨간색 / 주황색 / 노란색 / 초록색 / 파란색 / 보라색 / 회색입니다.
  • 파일 태그는 Finder와 연동되어 macOS Finder에서도 같은 색과 이름으로 보입니다.
  • Finder에서 태그 이름을 바꾸면 SnapView도 새로고침 후 같은 이름으로 보입니다.
  • 관리뷰에서는 폴더 태그도 지원합니다.
    • 네비게이터 row 우클릭 -> 태그
    • 네비게이터 헤더의 폴더 태그 필터
    • 메인뷰 정보 오버레이의 현재 폴더 태그 배지
    • 메인뷰 우클릭 메뉴의 현재 폴더 태그

7.4 Lightroom / Finder 연동

  • Lightroom과는 별점 / Pick / Reject를 XMP sidecar 기준으로 연동합니다.
  • Finder와는 태그(색상 포함)를 연동합니다.
  • SnapView의 강점은 여기서 드러납니다. 빠른 선별은 SnapView에서 끝내고, 결과는 Lightroom과 Finder에서 그대로 이어서 사용할 수 있습니다.
  • 즉, 별점/플래그는 Lightroom 워크플로우와 연결되고, Finder 태그는 macOS 파일 관리와 연결됩니다.

7.6 슬라이드쇼 전용 키

  • Shift + Enter: 시작 / 종료
  • Shift + Space: 레거시 시작 / 종료 호환
  • Space: 슬라이드쇼 활성 중 재생 / 일시정지
  • Esc: 종료
  • ← / →: 이전 / 다음
  • [ / ]: 느리게 / 빠르게
  • L: 루프 토글
  • S: 셔플 토글
  • I: 정보 오버레이 토글
  • 0: Fit 재적용
  • 전환 종류는 HUD 메뉴에서 하드 컷 / 크로스페이드 / 블랙 페이드 중 선택합니다.

7.6 복사/삭제/이동

  • Cmd+C: 선택 항목 복사
  • Cmd+V: 붙여넣기 (Grid/사진관리모드에서 주로 사용)
  • Delete 또는 D: 삭제
  • Cmd+Delete: 확인 없이 휴지통으로 이동
  • 설정 > 일반의 삭제 확인 없이 휴지통으로 이동을 켜면 Delete 또는 Backspace도 확인창 없이 macOS 휴지통으로 이동합니다.
  • 확인 없는 삭제 옵션은 기본 꺼짐이며, 영구 삭제를 수행하지 않습니다.
  • Move to Folder: 현재 이미지 또는 명시 선택 항목을 앱 내부에서 지정 폴더로 이동합니다.
  • Grid/Manage에서는 사용자가 명시 선택한 항목이 파일 작업 대상입니다. 선택이 없을 때만 현재 항목을 대상으로 삼습니다.

7.7 외부 앱으로 열기

  • 다른 앱으로 열기…는 현재 파일을 외부 앱으로 엽니다.
  • 같은 확장자 그룹에 대해 이전에 선택한 앱이 있으면 그 앱으로 바로 열고, 저장된 앱이 없으면 앱 선택창을 표시합니다.
  • Cmd + Option + O는 저장된 앱과 관계없이 앱 선택창을 직접 엽니다.
  • RAW+JPG 페어는 설정 > 일반 > 외부 앱으로 열 RAW+JPG 대상에서 RAW 우선 또는 JPG 우선으로 선택할 수 있습니다.
  • 기본값은 RAW 우선입니다.
  • ZIP 내부 항목은 외부 앱 열기 미지원입니다.

7.8 파일명 변경 (F2 / Rename…)

  • Main/Grid/Filmstrip/Compare 어디서든 F2 또는 메뉴 Rename…로 현재 파일명을 변경할 수 있습니다.
  • ZIP 내부 항목은 실제 파일 시스템 대상이 아니므로 이름 변경을 지원하지 않습니다.
  • 확장자는 유지되며, basename만 변경됩니다.
  • 설정 > Navigation의 파일명 변경 후 재정렬(Resort After Rename)이 켜져 있으면 rename 직후 현재 정렬 규칙으로 목록을 재평가하고 변경한 파일을 다시 선택합니다.
  • 옵션이 꺼져 있으면 현재 목록 순서를 최대한 유지한 채 파일명/경로만 갱신합니다.

7.9 촬영 시각과 위치 정보 편집

  • 지원되는 사진에서는 상세 정보 패널의 촬영시각/GPS 편집 버튼으로 날짜, 시간, 위치 정보를 수정할 수 있습니다.
  • 원본 파일에 안전하게 쓸 수 없는 형식이나 위치에서는 편집을 막고 안내를 표시합니다.
  • 동영상, ZIP 내부 항목, 접근 권한이 없는 파일은 메타데이터 편집 대상에서 제외될 수 있습니다.
  • 위치 정보를 고칠 때는 지도나 주소 검색 결과를 다시 확인한 뒤 저장하는 것을 권장합니다.

8. Quick Check와 Compare 사용법

8.1 Quick Check

  • K로 Quick Check 세트를 켭니다.
  • Quick Check 세트는 Quick Check + 상세 EXIF + 히스토그램을 함께 켜는 빠른 점검 모드입니다.
  • 점수와 경고 원인(초점/노출/눈감음/구도 등)을 확인합니다.
  • Quick Check는 보조 도구이며 최종 선택은 사용자가 합니다.
  • OCR 옵션을 켜면 Quick Check에서 사진 속 문자를 인식할 수 있습니다. 자동 OCR은 기본값이 꺼짐이며, 필요할 때만 켜는 것을 권장합니다.
  • 인식된 텍스트 하이라이트에 마우스를 올리면 텍스트를 확인할 수 있고, 클릭하면 클립보드에 복사됩니다.

8.2 Compare 모드

  • C로 Compare 모드 진입/종료
  • 기본 Selection 모드에서는 1~4장을 나란히 비교해 한 장을 고릅니다.
  • Compare 모드 안에서 R을 누르면 Selection과 Reference를 전환할 수 있습니다.
  • Compare 상단에는 Selection / Reference 세그먼트와 상태 텍스트가 표시되어 현재 비교 문맥을 바로 확인할 수 있습니다.
  • Reference 모드에서는 한 장을 기준으로 고정하고, 다른 후보를 좌/우로 넘기며 순차 비교할 수 있습니다.
  • Reference 모드에서는 Tab으로 기준/후보 포커스를 전환할 수 있습니다.
  • Reference 모드에서 ↑는 기준 포커스, ↓는 후보 포커스로 즉시 지정합니다.
  • Reference 모드에서 ←/→는 현재 포커스된 패널(기준 또는 후보) 이미지를 이동합니다.
  • Reference 모드의 평점/픽/리젝트/태그/삭제는 현재 포커스된 패널(기준 또는 후보)에만 적용됩니다.
  • Compare 삭제 확인 팝업에서 취소하면 비교 모드와 포커스 상태가 유지됩니다.
  • 새 소스(다른 파일/ZIP)로 전환하면 이전 Compare 상태는 자동으로 정리됩니다. 단, Resume Last Session 설정이 켜져 있고 같은 소스를 다시 열면 마지막 세션을 복원할 수 있습니다.
  • 확대해서 디테일까지 확인할 수 있습니다.

8.3 중복사진정리

  • Cmd+Shift+D: 중복 모드 진입(모드 내에서는 재스캔)
  • Shift+D 또는 ESC: 중복 모드 종료
  • ← / →: 이전/다음 중복 그룹 이동
  • Cmd+← / Cmd+→: 이전/다음 중복 그룹 이동
  • P: 현재 이미지를 기준이미지(Keep)로 지정
  • 우측 패널 하단에서 마지막 삭제를 Cmd+Z로 되돌릴 수 있습니다.

9. 설정과 동작 이해하기

9.1 디코딩 모드

  • 속도 우선: 빠른 탐색이 우선입니다. 기본적으로 더 작은 리사이즈 이미지를 먼저 보여줍니다.
  • 보통: 일반적인 추천값입니다. 기본은 리사이즈 이미지로 보고, 확대를 할 때 필요한 해상도로 점진적으로 화질을 올립니다.
  • 화질 최우선: 가능한 한 높은 해상도를 우선합니다. 화질 확인이 가장 중요할 때 적합합니다.

9.1.1 느린 저장장치 및 대형 이미지 동작 안내

  • 느린 네트워크나 외장하드에서는 스냅뷰가 버벅임을 방지하기 위해 사용자가 알아채지 못하게 화면 너머의 백그라운드 작업량을 자동으로 조절합니다.
  • 열리지 않는 손상된 포맷이나 너무 큰 대형 이미지의 경우, 화면에 나타나는 안내에 따라 안전하게 열기 버튼을 눌러 수동으로 이미지를 확인할 수 있습니다.

9.2 빠른 키보드 이동 프리뷰

  • Off: 빠른 이동 중 프리뷰를 쓰지 않습니다.
  • Auto: 일반적인 추천값입니다. 상황에 따라 프리뷰를 사용해 이동 체감을 부드럽게 만듭니다.
  • Aggressive: 빠른 연속 이동에서 프리뷰를 더 적극적으로 사용합니다.

이 설정은 연속 이동 체감에 영향을 주며, 사진을 한 장씩 천천히 보는 경우보다 빠르게 넘길 때 차이가 큽니다.

9.3 정보 오버레이 토글

  • I: 파일 정보/EXIF 표시
  • H: 히스토그램 토글
  • K: Quick Check 세트 토글

즉, K는 Quick Check만 따로 켜는 것이 아니라 점검에 필요한 정보 패널을 한 번에 여는 용도입니다.

9.4 오버레이 가독성 / 별점 UI

  • 설정 > 일반에서 오버레이 텍스트 그림자를 기본 / 강하게 / 자동으로 고를 수 있습니다.
  • 자동은 밝은 이미지에서만 그림자를 더 강하게 적용해 파일명과 간단 정보가 더 잘 보이게 합니다.
  • 설정 > 일반에서 별점 UI를 항상 표시 / 자동 / 숨김으로 조절할 수 있습니다.
  • 설정 > 일반에서 별점 UI 아래 사진 수 UI를 현재/전체 / 현재 / 미표기로 조절할 수 있습니다.
  • 자동은 별점이 있는 사진에서만 별점 UI가 보입니다.
  • 숨김을 써도 1~5, 0, \, 메뉴의 별점 기능은 그대로 사용할 수 있습니다.

9.5 창 닫기 동작

  • 설정 > 일반에 모든 창을 닫으면 종료 옵션이 있습니다.
  • 기본값은 꺼져 있습니다. 원할 때만 자동 종료로 바꿀 수 있습니다.

9.6 하위 폴더 이미지 포함

  • 설정에서 하위 폴더 이미지 포함을 켜면 현재 폴더뿐 아니라 하위 폴더의 이미지도 함께 탐색합니다.
  • 라이브러리 범위가 넓어져 편리하지만, 큰 폴더에서는 초기 스캔 범위와 결과 개수가 달라질 수 있습니다.

9.7 창 열기 정책 / 파일명 변경 후 재정렬

  • 설정 > 일반 > 창 열기 정책에서 단일 창(재사용) 또는 멀티 창(새 창 열기)를 선택할 수 있습니다.
  • 설정 > Navigation > 파일명 변경 후 재정렬을 켜면 rename 직후 목록을 재정렬합니다.

9.8 별점 후 자동 이동

  • 별점 후 자동 이동을 켜면 별점을 준 뒤 자동으로 다음 사진으로 넘어갑니다.
  • 빠른 1차 선별에서는 매우 유용하고, 세밀하게 비교할 때는 끄는 편이 좋습니다.
  • Cmd+A로도 토글할 수 있습니다.

9.9 컴페어 재진입 동작

  • 설정 > Navigation > 컴페어 진입 동작에서 진입 정책을 선택할 수 있습니다.
  • 현재 선택 기준(Current Context)은 현재 선택/현재 인덱스를 기준으로 컴페어를 시작합니다. (기본값)
  • 마지막 세션 복원(Resume Last Session)은 같은 소스(같은 폴더/ZIP)를 다시 열 때 마지막 Compare 구성과 포커스를 복원합니다.

9.10 화면 맨위 고정

  • 다른 앱과 함께 비교하거나 Finder/Lightroom과 번갈아 볼 때 유용합니다.
  • Cmd+Shift+T로 빠르게 켜고 끌 수 있습니다.

9.11 Pro JPG / ZIP 해상도

  • Pro 레이아웃에서는 일반 디코딩 모드와 별도로 Pro JPG 해상도, Pro ZIP 해상도 설정이 적용될 수 있습니다.
  • 즉, 일반 모드의 디코딩 우선순위와 Pro 모드의 해상도 정책은 완전히 같은 개념이 아닙니다.

9.12 스크롤 방향과 확대 유지

  • 설정 > Navigation에서 마우스 휠 동작을 이전/다음 이미지, 스크롤, 줌 중 선택할 수 있습니다.
  • 자연스러운 스크롤은 Apple 설정과 같은 의미로 동작합니다. 켜면 손가락/휠이 움직이는 방향을 콘텐츠 이동 방향처럼 해석해 이전/다음 방향을 반대로 적용합니다.
  • 스크롤 방향 직접 설정을 켜면 자연스러운 스크롤과 별개로 마우스/트랙패드, 상하/좌우 축의 이전/다음 방향을 각각 지정합니다.
  • 이미지 이동 시 확대 비율 유지를 켜면 다음 이미지로 넘어가도 현재 확대 비율을 유지합니다. 꺼져 있으면 이미지마다 기본 맞춤 표시로 돌아갑니다.

9.13 다크 배경과 툴팁

  • 설정 > 일반에서 다크 모드 뷰어 배경을 완전 검은색으로 바꿀 수 있습니다.
  • 상단 툴바 아이콘 위에 커서를 올리면 해당 버튼의 기능을 툴팁으로 확인할 수 있습니다.

10. ZIP 파일 사용 시 주의점

  • ZIP 내부 이미지도 일반 폴더처럼 탐색할 수 있습니다.
  • ZIP은 구조 특성상 폴더보다 느릴 수 있습니다.
  • ZIP 환경에서는 일부 정리 기능이 제한됩니다.
  • ZIP에서는 별점/Pick/Reject/Finder 태그 저장이 제한됩니다.
  • ZIP 내부 항목은 실제 파일이 아니므로 Finder 태그 연동 대상이 아닙니다.
  • ZIP에서는 복사/붙여넣기/삭제가 제한됩니다.
  • 중복사진정리에서 ZIP 항목은 스캔은 가능하지만 삭제 단계에서 자동 건너뜀 처리될 수 있습니다.

11. 성능을 높이는 방법

  1. 대용량/ZIP 탐색이 느리면 디코딩 모드를 속도 우선으로 변경합니다.
  2. 그리드에서는 썸네일 크기를 적당히 줄여 한 화면 밀도를 높입니다.
  3. 필요한 오버레이만 켜고( I, K, H) 불필요한 패널은 끕니다.
  4. 느린 외장 저장장치에서는 먼저 작은 폴더 단위로 정리합니다.

12. 자주 쓰는 단축키 요약

  • 뷰 전환: Q Grid, W Main View, E 가로 Filmstrip, R 세로 Filmstrip, T Navigator, Tab 프로 레이아웃 뷰
  • 중복사진정리: Cmd+Shift+D (진입/재스캔), Shift+D (종료)
  • 비교 모드: C
  • 이동: 좌/우, 상/하 = 이전/다음, Cmd+상/하 = 처음/끝, ⌥+상/하 = 이전/다음 폴더 첫 이미지
  • 점프 이동: Cmd+좌/우(10장), Cmd+Shift+좌/우(50장)
  • 줌: = / -, Fit 0, 100% 9
  • 정보 토글: I(정보), K(퀵체크 세트), H(히스토그램), M(지도)
  • 만화책 보기: B (진입/종료)
  • 동영상: Space (재생/일시정지/종료 후 다시 재생), Option+좌/우 (5초 탐색)
  • 화면: Enter(전체화면), Cmd+Shift+T(맨위 고정)
  • 선별: 1~5, 0, P, X, U, Cmd+1~6
  • 작업: Cmd+C, Cmd+V, Delete/Backspace/D, Cmd+Delete, Cmd+O, Cmd+Return(Show in Finder)
  • 선택: Cmd+A (Main=Auto Advance 토글, Grid/Manage=전체 선택)

13. 추천 워크플로우 (실전)

13.1 여행/일상 사진 빠른 정리

  1. Grid( Q)에서 전체를 훑습니다.
  2. Reject( X)를 먼저 표시해 불필요 컷을 줄입니다.
  3. Main( W) 또는 Filmstrip( E)으로 좋은 컷에 별점 3~5를 줍니다.
  4. 애매한 컷은 Compare( C)로 2~4장만 비교합니다.
  5. 최종 선택본을 복사/이동해 보관 폴더로 정리합니다.

13.2 RAW+JPG 혼합 촬영 정리

  1. 폴더를 열고 빠르게 탐색합니다.
  2. Quick Check( K)로 문제 컷을 빠르게 찾습니다.
  3. 별점/플래그로 선택 결과를 만든 뒤 Manage( R)에서 필터로 점검합니다.

13.3 Lightroom 연계 선별

  1. SnapView에서 1~5, P, X, U로 먼저 선별합니다.
  2. 이 상태는 sidecar(XMP)에 저장되어 Lightroom 계열 도구에서 이어서 확인할 수 있습니다.
  3. 후반 보정은 Lightroom에서 하고, 가장 시간이 많이 드는 1차 선별은 SnapView에서 훨씬 빠르게 끝내는 흐름에 적합합니다.

13.4 Finder 태그 중심 정리

  1. SnapView에서 Cmd+1~6으로 Finder 태그를 적용하거나 해제합니다.
  2. Finder에서도 같은 태그 이름과 색상이 보여 폴더 정리와 전달 단계가 쉬워집니다.
  3. SnapView 안에서는 별점/Pick/Reject와 함께 선별하고, Finder 밖에서는 태그로 상태를 즉시 이어갈 수 있습니다.

13.5 중복사진 정리 워크플로우

  1. Cmd+Shift+D로 중복사진정리 모드에 진입합니다.
  2. 좌측 그룹 리스트에서 용량이 큰 그룹부터 선택합니다.
  3. P로 기준이미지를 지정한 뒤, 카드 X 또는 우측 현재이미지 병합으로 정리합니다.
  4. 여러 그룹을 한 번에 정리할 때는 중복사진 일괄 정리를 사용합니다.
  5. 방금 삭제를 되돌려야 하면 즉시 Cmd+Z를 사용합니다.

14. 문제 해결 (FAQ)

Q1. 앱이 열리지만 파일이 안 보입니다

  • 지원 포맷인지 확인합니다.
  • 파일 권한 문제면 폴더를 다시 선택해 권한을 허용합니다.

Q2. 키보드 단축키가 안 먹습니다

  • 앱 창이 포커스를 가지고 있는지 확인합니다.
  • 다른 입력창(텍스트 필드)에 커서가 있으면 먼저 해제합니다.
  • 최근 버전에서는 Cmd+W 뒤 Finder에서 다시 열어도 보이는 메인 창을 우선 복구하도록 정리됐지만, 이미 다른 창에 포커스가 있으면 먼저 SnapView 창을 한 번 클릭해 주세요.

Q3. ZIP이 느리거나 실패 메시지가 나옵니다

  • 손상 ZIP인지 확인합니다.
  • 다시 압축하거나 파일을 다시 받아 테스트합니다.
  • 디코딩 모드를 속도 우선으로 낮춰봅니다.

Q4. 아이콘이나 버전 표기가 이상합니다

  • macOS가 이전 아이콘이나 버전 정보를 잠시 캐시할 수 있습니다. SnapView를 완전히 종료한 뒤 다시 실행해 보세요.
  • Applications 폴더에 SnapView가 하나만 있는지 확인하고, DMG 안의 앱이나 오래된 복사본을 실행 중이 아닌지 확인합니다.
  • DMG 버전은 앱 메뉴의 업데이트 확인(Check for Updates) 또는 최신 DMG 재설치로 확인합니다.
  • Mac App Store 버전은 App Store의 업데이트 화면에서 최신 버전인지 확인합니다.

15. 업데이트

  • DMG 채널(Fast): 앱 메뉴 업데이트 확인(Check for Updates)로 수동/자동 업데이트를 확인합니다. GitHub 릴리즈에서 SnapView.dmg로 수동 업데이트할 수도 있습니다.
  • Mac App Store 채널(Stable): Mac App Store의 업데이트 경로를 따릅니다.
  • DMG 채널은 별도 Intel 전용 파일 없이 최신 SnapView.dmg 하나로 업데이트합니다.

16. 데이터/안전 관련 참고

  • SnapView는 빠른 보기/선별 중심 도구입니다.
  • 삭제/즉시 삭제 전에는 선택 항목을 한 번 더 확인하세요.
  • 중요한 작업 전에는 원본 백업을 권장합니다.
