배포 방식 변경 안내

SnapView 2.7.1은 마지막 DMG 릴리즈입니다. SnapView 3.0부터 최신 버전과 모든 향후 업데이트는 Mac App Store에서 제공합니다.

마지막 홈페이지 다운로드 (DMG 2.7.1)

Apple Silicon과 Intel Mac을 지원하는 마지막 서명·공증 직접 배포 버전입니다.

  • ZIP 파일을 풀지 않고 내부 이미지를 바로 탐색
  • 폴더, ZIP, 이미지 파일을 빠르게 열고 탐색
  • 설치된 앱은 계속 사용 가능
  • 향후 기능 업데이트와 버그 수정은 제공되지 않음
  • 샌드박스 제약이 없어 파일 관리/정리 워크플로우에 더 유연함

2.7.1 직접 배포 버전이 꼭 필요한 경우에만 마지막 DMG를 이용해 주세요.

Mac App Store

SnapView 3.0 이후 최신 버전과 업데이트를 제공하는 기본 배포 경로입니다.

  • Mac App Store를 통한 간편한 설치 및 업데이트
  • ZIP 파일 내부 이미지 직접 탐색 지원
  • 폴더/이미지/ZIP 탐색 등 핵심 뷰어 기능 제공
  • 파일이나 폴더 접근 시 macOS 권한 허용 과정이 표시될 수 있음
  • App Store 심사와 안정화 과정을 거친 버전으로 제공

최신 버전과 향후 업데이트는 Mac App Store에서 받아 주세요.
