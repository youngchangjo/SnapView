개인정보 처리방침

SnapView가 로컬 사진과 선택형 사용 분석·안정성 진단을 처리하는 방법을 안내합니다.

로컬 사진과 파일

SnapView는 사용자가 연 사진, 폴더, ZIP 아카이브, Apple Photos 항목, 썸네일과 메타데이터를 Mac 안에서 처리합니다.

  • 사진, 파일 이름, 파일 경로, 폴더 이름, 이미지 메타데이터, EXIF, 위치, 계정 및 결제 정보는 SnapView 앱의 사용 분석이나 안정성 진단에 포함하지 않습니다.
  • 이미지 디코딩, 썸네일 생성, 캐싱, 메타데이터 읽기와 온디바이스 검토 기능은 로컬에서 처리합니다.
  • SnapView는 개인정보를 판매하지 않으며, 광고 식별자·광고 개인화·Firebase 사용자 ID를 사용하거나 앱과 웹사이트 사이에서 사용자를 추적하지 않습니다.

선택형 앱 사용 분석 및 안정성 진단

SnapView는 전반적인 제품 사용을 이해하고 앱 안정성을 개선하기 위해 Google Firebase Analytics와 Firebase Crashlytics를 포함합니다. 두 항목은 각각 별도로 선택할 수 있습니다.

  • 익명 사용 분석: 앱 실행과 세션, 뷰어 활성화, 연 소스 유형, 보기 모드, 탐색 구간, 기능 사용 범주, 메모리 압박 이벤트, 앱 버전, 운영체제 정보 및 Firebase 앱 인스턴스 측정 식별자가 포함될 수 있습니다.
  • 앱 안정성 진단: 크래시 데이터, 스택 추적, 앱·빌드 정보, 운영체제와 기기 실행 환경, 메모리·성능 측정값, 현재 보기 상태 및 범위가 제한된 기타 진단 값이 포함될 수 있습니다.
  • 해당 범주는 Product Interaction, Other Usage Data, Device ID, Crash Data, Performance Data 및 Other Diagnostic Data에 해당합니다. 분석 또는 앱 기능 개선 목적으로 사용하며 계정과 연결하거나 추적에 사용하지 않습니다.

동의와 배포 채널별 초기값

  • Mac App Store 빌드의 사용 분석과 진단 자동 전송 초기 선택은 모두 OFF입니다.
  • 직접 배포 DMG 빌드의 초기 초안 선택은 모두 ON이지만, 사용자가 선택 적용을 누르기 전에는 Firebase 원격 수집을 시작하지 않습니다.
  • 개인정보 단계를 건너뛰거나 닫으면 두 항목을 모두 OFF로 저장합니다.
  • SnapView 설정에서 사용 분석과 진단 자동 전송을 언제든지 각각 끌 수 있습니다.
  • 비정상 종료 후에는 이번만 보내기, 항상 자동 전송 또는 보내지 않기를 선택할 수 있습니다. 이번만 보내기는 이후의 자동 전송을 켜지 않습니다.

보유 및 삭제

  • 동의 선택은 사용자가 변경하거나 앱 설정을 제거할 때까지 Mac에 로컬로 저장합니다.
  • 진단 자동 전송이 꺼져 있으면 전송 여부를 선택할 수 있도록 직전 비정상 종료의 범위가 제한된 로컬 스냅샷 한 건을 보관할 수 있습니다. 답하지 않은 이전 기록은 더 새로운 기록으로 대체하며, 사용자가 선택하면 로컬 스냅샷을 삭제합니다.
  • 보내지 않기를 선택하거나 설정에서 진단을 끄면 앱이 관리하는 미전송 Crashlytics 보고서를 삭제하고 이후 자동 업로드를 중단합니다. 사용 분석을 끄면 이후 분석 수집을 중단합니다.
  • 이미 전송된 데이터는 Google Firebase의 서비스 제어와 보유 정책에 따라 처리합니다. SnapWorks Lab은 SnapView 운영과 개선에 필요한 기간에만 원격 분석·진단 데이터를 보유하며, 적용 가능한 기록의 삭제 요청이나 문의는 이메일로 접수합니다.

시스템 권한

SnapView는 사용자가 선택한 파일과 폴더, 외장 드라이브 또는 Apple Photos 접근 권한을 요청할 수 있습니다. 이 권한은 사용자가 요청한 보기와 정리 작업을 제공하는 데만 사용합니다.

웹사이트 분석

SnapView 공식 웹사이트(snapview.snapworkslab.com)는 방문과 페이지 이용 현황을 이해하기 위해 Google Analytics를 사용할 수 있습니다. 웹사이트 분석은 앱과 분리되어 있으며 SnapView에서 연 사진이나 파일에 접근할 수 없습니다.
