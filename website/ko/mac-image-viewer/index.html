SnapView
기능 다운로드 매뉴얼 EN
Mac image viewer

폴더 속 이미지를 바로 넘겨보는 Mac 이미지 뷰어.

SnapView는 이미지를 가져오기 전에 먼저 확인하고, 비교하고, 필요한 파일만 정리하려는 Mac 사용자에게 맞춘 폴더 중심 이미지 뷰어입니다.

SnapView 다운로드 Mac App Store 마지막 DMG 2.7.1

2026년 7월 현재 한국 Mac App Store 등록 페이지 기준: 55개 평가, 5.0 평점.

짧은 답변

SnapView는 Mac에서 폴더 속 이미지를 빠르게 넘겨보고 WebP, HEIC, GIF까지 가볍게 확인할 수 있는 빠른 이미지 뷰어입니다. 사진 라이브러리로 먼저 가져오기보다 Finder 폴더, ZIP 압축, RAW 파일, 혼합 포맷 이미지를 바로 확인하는 흐름에 맞췄습니다.

이런 사용자에게 맞습니다

  • Finder 폴더 안의 이미지를 빠르게 넘겨보고 싶은 Mac 사용자.
  • 편집이나 공유 전에 사진, 스크린샷, 디자인 참고 이미지를 먼저 고르는 사용자.
  • 키보드 이동, 별점, Pick/Reject, 색상 라벨, 파일 전달 흐름이 필요한 사용자.
  • WebP, HEIC, GIF, RAW, ZIP 압축과 여러 정지 이미지 포맷을 한 흐름에서 확인하려는 사용자.

가져오기보다 먼저 보는 작업에 맞췄습니다

사진 정리는 보통 폴더를 열어 어떤 컷을 남길지 보는 것에서 시작합니다. SnapView는 로컬 폴더, ZIP 압축, Apple Photos, RAW 파일, 여러 이미지 포맷을 한 흐름에서 확인할 수 있게 설계했습니다.

폴더 맥락 유지

Main, Grid, Filmstrip, Navigator, Pro Layout 보기로 현재 이미지와 주변 이미지를 함께 확인합니다.

키보드 중심 선별

넘겨보기, 별점, Pick/Reject, 색상 라벨, 보기 전환을 이미지 리뷰 흐름 안에서 이어갑니다.

다양한 이미지 포맷

JPG, PNG, HEIC/HEIF, WebP, GIF, TIFF, PSD, JPEG 2000, DICOM, EXR/HDR, TGA, RAW, 지원되는 동영상과 ZIP을 확인합니다.

선택 결과 이어가기

고른 파일을 Finder, 데스크탑, 편집 앱, Photos로 넘기고 Quick Organize, Batch Actions, 인쇄/PDF 저장으로 이어갑니다.

작업 흐름에 맞춰 쓰기

SnapView는 모든 미디어 작업을 대체하려는 앱이 아닙니다. 많은 이미지를 훑고, 포맷을 확인하고, 필요한 파일을 다음 단계로 넘기는 리뷰 구간에 초점을 둡니다.

이미지 작업에 맞는 도구를 고르기 위한 비교입니다.
SnapView 폴더 중심 이미지 리뷰, 키보드 이동, 혼합 포맷, ZIP 압축, 별점, 라벨, 파일 전달 흐름에 맞습니다.
macOS 미리보기 내장 단일 파일 보기, 마크업, 주석, PDF 작업, 기본 macOS 작업에 맞습니다.
카탈로그 편집 앱 장기 보관, 라이브러리 관리, 컬렉션, 깊은 편집 작업이 필요할 때 이어가기 좋습니다.

맥 이미지 뷰어 FAQ

SnapView는 무료인가요?
Mac App Store 기본 뷰어를 무료로 사용할 수 있고, 마지막 DMG 릴리즈인 SnapView 2.7.1도 GitHub 릴리즈에서 받을 수 있습니다.
Apple Silicon Mac에서 사용할 수 있나요?
마지막 2.7.1 DMG는 Apple Silicon과 Intel Mac을 위한 유니버설 Mac 앱으로 배포됩니다.
미리보기를 완전히 대체하나요?
이미지 폴더 탐색에는 SnapView를 사용할 수 있지만, 미리보기는 마크업, PDF, 기본 macOS 작업에 계속 유용합니다.
어떤 이미지 포맷을 열 수 있나요?
JPG, PNG, GIF, WebP, HEIC/HEIF, TIFF, PSD, JPEG 2000, DICOM, EXR/HDR, TGA, RAW, 지원되는 동영상과 ZIP 압축 이미지를 확인할 수 있습니다.
App Store에서도 받을 수 있나요?
네. SnapView 3.0과 향후 업데이트는 Mac App Store에서 제공하며, 마지막 2.7.1 DMG는 별도로 계속 받을 수 있습니다.
